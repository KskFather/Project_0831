## 자기소개

안녕하세요! 저는 **김이남**입니다. 2001년생으로 올해 스물다섯이 되었고, 대전에서 나고 자라 지금은 서울에서 자취하며 지내고 있습니다.

### 하는 일

컴퓨터공학을 전공하고 작년에 졸업한 뒤, 지금은 스타트업에서 백엔드 개발자로 일하고 있습니다. 서버 API 설계와 데이터베이스 운영을 주로 맡고 있고, 요즘은 회사에서 새로 도입한 클라우드 인프라를 익히느라 매일이 배움의 연속입니다.

### 성격과 가치관

낯을 조금 가리지만 친해지면 말이 많아지는 편입니다. 완벽하게 준비하기보다 일단 부딪혀 보면서 배우는 것을 좋아하고, 실수해도 다음에 고치면 된다는 마음으로 일합니다. 동료들과 편하게 의견을 나누는 분위기를 중요하게 생각하고, 혼자 끙끙대기보다 빨리 물어보고 빨리 해결하는 쪽을 선호합니다.

### 취미와 관심사

- **헬스**: 퇴근 후 거의 매일 헬스장에 들러 스트레스를 풉니다.
- **게임**: 주말엔 친구들과 온라인 게임을 즐겨 합니다.
- **사이드 프로젝트**: 회사 업무 외에 개인적으로 작은 앱을 만들어보는 걸 좋아합니다.
- **카페 투어**: 새로 생긴 카페를 찾아다니며 사진 찍는 것도 소소한 낙입니다.

### 앞으로의 목표

가까운 목표는 실력을 더 키워서 팀에서 없어서는 안 될 개발자가 되는 것이고, 장기적으로는 제 이름을 걸고 만든 서비스를 세상에 내놓아 보고 싶습니다. 이 프로젝트에서도 이것저것 새로운 시도를 해보면서 성장해 나갈 예정입니다. 잘 부탁드립니다!
